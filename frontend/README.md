# bulut-filo-yonetimi-web

React 19 + TypeScript + Vite frontend for Bulut Filo Yönetimi.

See the [repository root README](../README.md) for installation, the
overall architecture, and the list of available screens.

## Scripts

```
npm run dev          # start the Vite dev server
npm run build         # tsc -b && vite build
npm run lint          # oxlint
npm run typecheck     # tsc --noEmit
```
